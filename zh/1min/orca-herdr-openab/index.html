你該信任 Agent 多少？Orca、Herdr、OpenAB Connect

2026 年 10 月 15 日
9:41

下載 MP4

Herdr・押編排一個畫面排很多 git worktree 的 Agent，一眼看出誰在跑、誰卡住、誰可以合併。重點是編排與可見性。
Orca・押工作台把多個 Agent 收進一個工作台，像 IDE 一樣切換、檢視每個 Agent 的狀態，重點是集中的操作台。
OpenAB Connect・押信任Agent 和它動手的電腦分開，權限由你決定——observe 只給看、desktop 操作桌面、owner 全部工具。重點是信任邊界。
