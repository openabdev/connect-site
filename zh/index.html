分散運行在你的私有基礎架構,各自沙箱。關掉 app,它們繼續跑。

這是什麼

你的 agent 跑在某處。它把事情做到一半時,你想要的是**那裡**的一個 shell —— 同一個映像、同一個 workspace、同一批檔案,而不是在筆電上重現一次。

這個 shell 刻意沒有權限。它以 uid 1000 開啟,沒有 sudo、沒有 service-account token、沒有主機憑證,根檔案系統唯讀,workspace 用完即棄。

runtime 從不監聽可路由的位址。只有 Tailscale sidecar 擁有網路身分,兩者在 pod 內經 loopback 通訊。

兩端都是你的

  • 這裡沒有任何服務。app 連上的每一台伺服器都是你自己部署的 —— 在你自己的 Kubernetes 叢集,或你自己的 AWS 帳號裡。
  • 不需要帳號、不需要註冊、沒有遙測。你輸入的憑證留在 macOS Keychain,除了你自己的 runtime 之外不會送到任何地方。
  • runtime 是 MIT 開源的:openabdev/openab-pty。你可以確認自己到底部署了什麼,也可以照 客戶端契約寫自己的客戶端。這個 app 只是其中一種實作,它不是開源的。

部署

你點三下,它做八件事:產生憑證存進 Keychain、確認 namespace、建立 secret 與儲存、套用 pod、等它就緒、等它加入你的 tailnet、驗證管理端。不必寫 manifest,也不必開任何對外連接埠。

每個 agent CLI 一個映像 —— Claude Code、Codex、Cursor、Kiro、Gemini、Copilot 等。native 版本不含任何 agent。

沒有叢集也能試

app 的應用程式選單裡有離線的 Demo Mode:兩個範例連線和一個預錄的終端,完全不建立任何網路連線。它的存在就是為了讓你在部署任何東西之前先評估這個 app。
